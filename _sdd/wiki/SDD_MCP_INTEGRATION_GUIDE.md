# SDD 范式与 MCP 集成使用指南

## 🎯 概述

本文档详细说明如何在 SDD 范式中有效利用 MCP (Model Context Protocol) 服务器，增强规范驱动开发的效率和准确性。

## 📊 当前可用 MCP 服务器分析

### 1. **Context7 MCP Server** - 技术文档查询
**用途**：获取最新的技术库文档和代码示例
**在 SDD 中的作用**：
- 技术方案设计时的参考资料
- 验证技术选择的可行性
- 获取最佳实践和代码示例

**核心工具**：
- `resolve-library-id` - 解析库名到标准ID
- `get-library-docs` - 获取详细的库文档

### 2. **Deep Wiki MCP Server** - 知识库查询
**用途**：获取开源项目的深度文档
**在 SDD 中的作用**：
- 学习类似项目的架构设计
- 参考行业最佳实践
- 获取技术选型的详细说明

### 3. **Playwright MCP Server** - 自动化测试和验证
**用途**：浏览器自动化和端到端测试
**在 SDD 中的作用**：
- 功能验证和测试
- 用户界面测试
- 性能测试和监控

### 4. **IDE MCP Server** - 代码质量分析
**用途**：获取代码诊断信息和执行代码
**在 SDD 中的作用**：
- 代码质量检查
- 静态分析和问题识别
- 代码执行和验证

```markdown

   - 验证技术方案的可行性

   - 识别技术债务和改进点
```

```markdown
# SDD 任务分解阶段的 MCP 使用

2. **技术验证** (Context7)：
   - 验证技术方案的细节

   - 规划测试策略

指令示例：
"请使用 IDE 分析当前代码库的复杂性，使用 Context7 验证技术实现方案，并使用 Playwright 规划测试策略。"
```

### Phase 5: Implement (实现执行) + IDE + Playwright
```markdown

请重点使用 IDE 和 Playwright：

1. **代码质量保证** (IDE)：
   - 实时代码诊断
   - 静态分析检查
   - 类型安全验证

2. **功能验证** (Playwright)：
   - 自动化功能测试

3. **文档查询** (Context7)：
   - 获取实现指导
   - 解决技术问题

```

```markdown
1. **代码质量验收** (IDE)：
   - 最终代码质量检查
   - 性能分析
   - 安全性检查

2. **功能验收** (Playwright)：
   - 端到端功能测试
   - 用户体验验证
   - 兼容性测试

3. **文档验收** (Context7 + Deep Wiki)：
   - 技术文档完整性检查
   - 最佳实践对比验证

指令示例：
"请使用 IDE 进行最终代码质量检查，使用 Playwright 进行完整的端到端测试，并使用 Context7 验证技术实现符合最佳实践。"
```
